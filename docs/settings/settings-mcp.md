# Settings: MCP servers

Every setting in Settings › MCP servers: type, default, values and what it does.

These settings are in **Settings › MCP servers** (and in your `settings.json`).

### `ember.mcp.alwaysAsk`

MCP servers whose tools always ask before they run, in every mode except **Run everything** (Settings › MCP servers › Always ask).

- **Type:** array
- **Default:** `[]`
- **Scope:** Application (all windows and profiles)
