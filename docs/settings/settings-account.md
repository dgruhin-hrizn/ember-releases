# Settings: Accounts

Every setting in Settings › Accounts: type, default, values and what it does.

These settings are in **Settings › Accounts** (and in your `settings.json`).

### `ember.claudePath`

Absolute path to the `claude` CLI. Empty = find it on your login shell `PATH`. Ember always uses your own CLI so requests bill to your Claude subscription.

- **Type:** string
- **Default:** empty
- **Scope:** Machine (this computer, never synced)
