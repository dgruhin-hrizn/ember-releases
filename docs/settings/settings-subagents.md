# Settings: Subagents

Every setting in Settings › Subagents: type, default, values and what it does.

These settings are in **Settings › Subagents** (and in your `settings.json`).

### `ember.subagents.default`

Override for subagents without their own row (edit in **Ember: Settings → Subagents**).

- **Type:** object
- **Default:** `{"model":{"mode":"default"},"effort":{"mode":"default"}}`
- **Scope:** User or workspace

### `ember.subagents.overrides`

Per-subagent model/effort overrides and Disabled, keyed by subagent name (edit in **Ember: Settings → Subagents**).

- **Type:** object
- **Default:** `{}`
- **Scope:** User or workspace
