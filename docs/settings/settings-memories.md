# Settings: Rules and memories

Every setting in Settings › Rules and memories: type, default, values and what it does.

These settings are in **Settings › Rules and memories** (and in your `settings.json`).

### `ember.memories.enabled`

Give new chats the memories you added (Settings › Rules and memories) as always-on rules. Off keeps them without using them.

- **Type:** boolean
- **Default:** `true`
- **Scope:** User or workspace

### `ember.rules.userRules`

User rules: given to every Ember chat. One rule per item.

- **Type:** array
- **Default:** `[]`
- **Scope:** User or workspace
