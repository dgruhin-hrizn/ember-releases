# Keyboard shortcuts

Every Ember shortcut on macOS, Windows and Linux, the VS Code essentials, and the VS Code keys Ember changes.

Change any of these in **Settings › Keyboard** (it opens the editor's Keyboard Shortcuts with Ember's commands). A shortcut that works only somewhere — the chat panel, an editor, the terminal — says so in **Works when**.

## VS Code essentials

The editor's own keys still work in Ember. A few you'll use every day. In an editor, ⌘K / Ctrl+K is inline edit, so two-key shortcuts that start with it (like ⌘K ⌘S) work from outside the editor, for example after clicking the Explorer.

| Keys (macOS) | Keys (Windows and Linux) | What it does |
|---|---|---|
| `⌘P` | `Ctrl+P` | Go to a file |
| `⇧⌘P` | `Ctrl+Shift+P` | Command Palette |
| `⌘B` | `Ctrl+B` | Show or hide the side bar |
| `⌘J` | `Ctrl+J` | Show or hide the panel (terminal, problems, output) |
| `⌃`` | `Ctrl+`` | Show or hide the terminal |
| `⌘\` | `Ctrl+\` | Split the editor |
| `⇧⌘F` | `Ctrl+Shift+F` | Search in files |
| `⇧⌘E` | `Ctrl+Shift+E` | Explorer |
| `⌘K ⌘S` | `Ctrl+K Ctrl+S` | Keyboard Shortcuts (change any key) |
| `⇧⌘M` | `Ctrl+Shift+M` | Problems |

## VS Code defaults Ember changes

Ember takes a few of the editor's default keys for its own commands. The keys on the left do this in Ember; on the right is what they do in stock VS Code. Rebind any of them in Settings › Keyboard.

| Keys (macOS) | Keys (Windows and Linux) | In Ember | Without Ember |
|---|---|---|---|
| `⌘,` | `Ctrl+,` | Ember Settings | The editor's Settings (in Ember, ⌥⌘, / Ctrl+Alt+,) |
| `⌘E` | `—` | Swap the side bar and the chat | Find with the selection |
| `⌘K` | `Ctrl+K` | Inline edit (text is selected in an editor) | Starts two-key shortcuts such as ⌘K ⌘S, which work whenever nothing is selected (to write new code at the cursor, press ⌘K ⌘G) |
| `⌘K` | `—` | Write a terminal command with Claude (in the terminal) | Clear the terminal |
| `⌘L` | `Ctrl+L` | Show or hide the chat; with a selection, add it to the chat | Expand the line selection |
| `⌘I` | `Ctrl+I` | Show or hide the chat | A second key for Trigger Suggest |
| `⇧⌘L` | `Ctrl+Shift+L` | New chat (no editor or search result has focus) | Select all occurrences of the find match, which still works in an editor |
| `⇧⌘I` | `Ctrl+Shift+I` | New chat (on Linux, no editor has focus) | Open the chat in agent mode; on Linux, Format Document, which still works in an editor |
| `⇧⌘R` | `Ctrl+Shift+R` | Review changes | Refactor… (Windows and Linux; on macOS it's ⌃⇧R) |
| `⌘Y` | `Ctrl+Y` | Keep the change under the caret (the file has changes from a chat to review) | Redo (Windows and Linux) |
| `⌘N` | `Ctrl+N` | Undo the change under the caret (the file has changes from a chat to review) | New file |
| `⌘⏎` | `Ctrl+Enter` | Keep all changes in the file (the file has changes from a chat to review) | Insert a line below |
| `⌘Z` | `Ctrl+Z` | Undo the last Keep (right after a Keep, in that file) | Undo |
| `⇧⌘V` | `Ctrl+Shift+V` | Plan preview or its Markdown (a plan is open) | Markdown preview |
| `⌃Tab` | `Ctrl+Tab` | Switch chats (the chat panel has focus) | Switch editors |
| `⌘T` | `Ctrl+T` | New chat (the chat panel has focus) | Go to a symbol in the workspace |
| `⌘W` | `Ctrl+W` | Close the chat tab (the chat panel has focus) | Close the editor |
| `⌘D` | `Ctrl+D` | Open the chat in an editor tab (the chat panel has focus) | Add the next match to the selection |
